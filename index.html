Distributed Print-Fleet Service Work

What it does: lets several sites (offices, branches, shop floors) share and manage their receipt/label printers from one central dashboard — instead of setting up and troubleshooting each printer machine-by-machine, on site.

A self-hosted platform that turns USB thermal printers into a managed, multi-site network resource. Raspberry Pi edge agents expose printers over an authenticated HTTP API with reboot-safe job queues — so a print job is never lost or double-printed if a device restarts. A central control plane handles device enrollment, access tokens, job dispatch, status callbacks, and over-the-air (OTA) updates to the whole fleet — with a web dashboard and hardened deployment.

Package Optimization Service Work

What it does: automatically tells warehouse staff the best-fit shipping box for each order — cutting wasted space, packaging cost, and the guesswork of picking a box by eye.

A FastAPI microservice that recommends the optimal shipping box using 3D bin-packing — a packing algorithm (Google OR-Tools CP-SAT) that fits items in three dimensions while respecting fragility, weight-stacking and rotation rules. Packing runs as background jobs the caller can poll for progress, caches recurring scenarios, and runs in isolated worker processes so a solver crash degrades a single recommendation instead of taking down the whole service. 200+ tests, Dockerized.

Origin: rebuilt from a flawed AI-generated prototype into a production-grade service.

AI-Powered IT Support Bot Work

What it does: a Telegram chatbot that handles everyday IT requests from staff — answering common questions and walking people through fixes — so the team is only pulled in for the issues that genuinely need a human.

An AI/LLM-backed bot that automates first-line ("L1" — the routine front-desk tier) IT support end-to-end: tickets are checked against an FAQ/SOP/solutions knowledge base, the bot guides users through known fixes, and escalates only what needs a person — with common remediations (e.g. automatically restarting a stuck virtual machine) wired into the flow.

Impact: handles routine L1 tickets end-to-end, freeing the IT team to focus on higher-value engineering instead of repetitive support.
